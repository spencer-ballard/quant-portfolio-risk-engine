# # Institutional Portfolio Analytics Dashboard

A Python-based portfolio analytics platform designed to replicate
institutional investment research workflows.

## Features

- Portfolio performance analytics
- Risk measurement
- CAPM analysis
- Value at Risk
- Expected Shortfall
- Portfolio optimization
- Interactive dashboards


## Data Sources

- Yahoo Finance
- FRED Economic Data


## Technologies

Python
Pandas
NumPy
Plotly
Statsmodels
PyPortfolioOpt
